# Intercellular-Communication-in-the-AKI-CKD-Fibrosis-Transition
Reproducible code and analysis repository for a multi-evidence, convergence-based study of extracellular-vesicle (EV) communication in the acute-to-chronic kidney disease transition. This repository is structured to serve as the Data &amp; Code Availability artifact for publication.
