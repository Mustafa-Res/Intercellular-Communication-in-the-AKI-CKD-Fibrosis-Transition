# Step 1 — Pre-registration:

Everything in this folder was fixed **before** any analysis ran:

* `docs/PLAN.md` — the frozen pre-registration: the five-pillar phase-gated
design, per-gate pass/fail criteria with numeric thresholds, the language
ceiling (discovery-grade association language only).
* `docs/PLAN\\\_pillar1.md` — execution addendum for Phase 1.
* `config/` — run configuration (Phase-1 cohort list and parameters).
* `feasibility/` — phase-0 feasibility audit (`phase0\\\_feasibility\\\_audit.csv`)
and the selected-cohort table (`pillar1\\\_cohorts\\\_selected.csv`).
