# `docs/`

Frozen study documentation — the pre-registered design and its addenda. These
are **historical records**; they are not edited to match later folder renames.

* `PLAN.md` — the frozen pre-registration: phenotype, 5-pillar phase-gated
design, gene-set evidence model, gate criteria, and CHANGELOG. It uses the
*original* planned phase vocabulary (`01\\\_feasibility`, `02\\\_bulk\\\_signature`, and
the planned Pillars 3–5 = spatial / genetics / urinary-EV). The executed study
concluded at four pillars; the top-level `README.md` gives the
as-planned → as-executed folder map.
* `PLAN\\\_pillar1.md` — Pillar-1 execution addendum (bulk-signature specifics).

Gate verdicts and per-pillar memos live with the results, under each numbered
`results/` folder and consolidated in `results/gates/`.
